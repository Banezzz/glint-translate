Glint 划词翻译 隐私政策

生效日期：2026 年 10 月 20 日

English version below

Glint 划词翻译（以下简称「Glint」）是一个 Chrome 扩展，用你自己配置的大模型服务翻译网页上的文字。Glint 没有自己的服务器，开发者不会收到、存储或查看你的任何数据。

Glint 处理哪些数据

  • 设置：你填写的 API 地址、API Key、模型名称和偏好设置（目标语言、主题、界面语言、提示词等）。
  • 要翻译的文字：你选中的文字；开启网页翻译后，页面上进入视口的段落文字和网页标题；以及你在弹出面板中输入的文字。

数据存在哪里、发给谁

  • 设置只保存在你本机浏览器的 chrome.storage.local 中，不会同步到云端，也不会发送给开发者。
  • 要翻译的文字只会发送到你自己配置的 API 地址（例如 OpenAI、Anthropic、DeepSeek 或本地运行的 Ollama），API Key 也只随这些请求发送给该地址。这些服务如何处理数据，适用它们各自的隐私政策。
  • 网页翻译只在你点击悬浮球、按快捷键、使用右键菜单或弹出面板后才会开始；划词翻译只在你选中文字并触发翻译时进行。
  • 语言识别使用浏览器内置的 chrome.i18n.detectLanguage，朗读使用浏览器内置的语音合成，都在本机完成。
  • 最近的翻译结果会暂存在扩展的后台内存中，以便重复请求时立即显示；浏览器关闭或后台休眠后即被清除。

Glint 不做的事

  • 不包含任何统计、分析、广告或第三方追踪代码。
  • 不收集浏览历史，不读取与翻译无关的页面内容。
  • 不出售、不出租、不共享你的数据，也不将其用于翻译以外的任何目的，包括信用评估或贷款用途。
  • 不从远程加载或执行代码，扩展的全部代码都包含在安装包内。

权限说明

  • storage：在本机保存你的设置。
  • contextMenus：提供「用 Glint 翻译」和「翻译此网页」右键菜单。
  • scripting：向安装或更新扩展前已经打开、尚未加载翻译脚本的标签页注入扩展自带的脚本，以及在弹出面板中读取当前页面选中的文字。
  • 访问所有网站（<all_urls>）：在任意网页上划词和翻译整页，并向你自定义的 API 地址发送请求。

删除数据

卸载 Glint 会删除它保存在本机的全部设置。你也可以在设置页中清空 API 地址和 Key。

变更与联系

如果本政策有变化，会更新本页面并修改生效日期。Glint 是开源项目，源代码见 GitHub。有任何问题，请在 GitHub Issues 中提出。

Glint Translate Privacy Policy

Effective date: October 20, 2026

Glint Translate ("Glint") is a Chrome extension that translates text on web pages with a language model service that you configure yourself. Glint has no servers of its own; the developer never receives, stores or sees any of your data.

What Glint handles

  • Settings: the API endpoint, API key and model you enter, and your preferences (target language, theme, interface language, prompts and so on).
  • Text to translate: text you select; when page translation is on, the paragraphs that scroll into view and the page title; and text you type into the popup.

Where data is kept and where it goes

  • Settings are stored only in your browser's chrome.storage.local. They are not synced and never sent to the developer.
  • Text to translate is sent only to the API endpoint you configured (for example OpenAI, Anthropic, DeepSeek or a local Ollama), together with your API key for that endpoint. How those services handle data is governed by their own privacy policies.
  • Page translation starts only after you click the floating ball, press the shortcut, or use the context menu or popup. Selection translation runs only when you select text and trigger a translation.
  • Language detection uses the browser's built-in chrome.i18n.detectLanguage and read-aloud uses the browser's built-in speech synthesis; both run on your device.
  • Recent translations are kept in the extension's background memory so repeated requests show instantly; they are cleared when the browser closes or the background worker sleeps.

What Glint does not do

  • No analytics, advertising or third-party tracking code.
  • No collection of browsing history, and no reading of page content unrelated to a translation you asked for.
  • Your data is not sold, rented or shared, and is not used for any purpose other than translation, including creditworthiness or lending.
  • No remote code: everything the extension runs ships inside the package.

Permissions

  • storage: keep your settings on this device.
  • contextMenus: the "Translate with Glint" and "Translate this page" context menu items.
  • scripting: add the extension's bundled translation script to tabs that were open before it was installed or updated and do not have it yet, and read the current selection for the popup.
  • Access to all sites (<all_urls>): translate selections and whole pages on any site, and send requests to the API endpoint you choose.

Deleting your data

Uninstalling Glint removes all settings it stored on your device. You can also clear the API endpoint and key in Settings.

Changes and contact

If this policy changes, this page will be updated along with its effective date. Glint is open source; see the code on GitHub. For questions, open an issue on GitHub Issues.
